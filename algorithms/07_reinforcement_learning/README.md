# Reinforcement Learning

Reference implementations of algorithms that improve decisions from
state-action-reward interactions. Start with **tabular Q-learning**, then
explore policies, planning and function approximation as future contributions.

## Implemented algorithms (1)

| Algorithm | What it does |
| --- | --- |
| [`tabular_q_learning`](tabular_q_learning/README.md) | Learns discounted action values from recorded transitions using temporal-difference updates. |

Each entry documents the update rule, behavioral assumptions, input
validation, complexity, limitations and runnable tests.
